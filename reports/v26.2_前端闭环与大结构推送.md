# v26.2 · 图上标记闭环 / 微信口径同步 / 大结构信息推送

日期：2026-11-10　｜　性质：前端交互 + 一条信息推送，**不动引擎、不动账本、不重跑盲测**

## 0. 起因

用户反馈「部分图上有图标，但下方信号栏没有相关信息」。逐层对账后确认：图表叠了 **6 套数据源**，
信号栏只收 **4 类**（它是微信口径的当日消息流归档，不是图例索引）。7 品种合计图上约 1532 个
标记数据项、信号栏 793 行。其中既有刻意分工，也有三处真遗漏：

| 遗漏 | 表现 |
|---|---|
| 图标点击只覆盖 3 类 | 黄◆、青◇、白箭头、▮方案方块点了没反应，且全页无 tooltip |
| 信号栏没跟上 v25 ②通道 | 微信推 `mw` / `tf` 形态，页面按 v11 隐藏 confirm + v13 隐藏 WM 的老规则查不到 |
| 口径不透明 | 周/月线时列表仍是日线却无提示；筛选状态会整批藏掉类目；无「哪类去哪查」的说明 |

## 1. 模块一 · 所有图标点击闭环 + 全局 tooltip

`templates/pro.html` 的 `renderChart()` 里给每类标记补 payload，统一由 `markTip()` 出提示、
`CH.on('click')` 分发到详情弹窗：

| 图上图标 | payload | 点击弹窗 |
|---|---|---|
| 蓝▼/紫▲、灰◆ 信号 | `sig`（原有） | `openSig` |
| ○ 白圈失效 | `defDate`（原有） | `openDef` |
| ★ 结构双顶/底 | `mwDate`（原有） | `openMw` |
| • 动能真空小黄点 | `vacSig`（新增） | `openSig` |
| ◇ 盘整预警 / ➤ 白箭头 | `exData` + `exKind`（新增） | `openExitTrade` |
| 黄◆ 建议/强烈离场（含外叠虚线圈） | `srcData`（新增） | `openExitSignal` |
| ▮进多 / ▮进空 / 出·xxx 方块 | `pmData`（新增） | `openPlanMark` |

- ECharts 加**全局 `tooltip`**：`trigger:'item'`、`triggerOn:'mousemove|click'`，
  信号层给图标说明，K 线给 开/收/低/高，均线返回空串不弹空框。手机长按由 ECharts 触屏映射支持。
- 新增弹窗一律是「历史 / 复盘 / 形态」信息，方案回测方块与形态归档都挂
  `[研究参考·非建仓指令]`；**不改变任何平仓线、不加任何新信号**。

## 2. 模块二 · 微信口径同步（纪律优先）

微信「🔥 方案内信号」允许 `pred / warn / mw / confirm / tf` 五种形态，其中 `mw` / `tf`
在旧前端被隐藏。现在信号栏补**只读形态归档**：

- 范围 = 图上可见的 `hiConf` 结构 ∪ 信息推送级大结构 ∪ `plan.marks` 里的「转折确认」(tf)。
  小结构（既不上图也不推送）不进列表，避免稀释。
- 每行 badge 强制完整显示 `[研究参考·非建仓指令]`；文案只写形态、日期、间隔、深度、
  级别、只读提示，**零动作字眼**。
- `archDiscipline()` 运行时断言：剔除固定标签后扫描
  `进场 / 开仓 / 建仓 / 做多 / 做空 / 反手 / 可尝试 / 次日开盘 / 下单`，
  未带标签或命中禁词 → `console.error` 并**拦下整行**。
- 卡片标题由「信号栏 · 进场 / 出场」改为「信号栏 · 消息归档」，计数改「信号 N · 离场 N」，
  筛选「只看进场」改「只看信号」，消除整卡歧义；新增「研究参考」筛选。
- 点击归档行 → `openArchive()` 纯只读弹窗（可一键在 K 线定位形态），**不会**打开任何含操作按钮的弹窗。

## 3. 大级别结构双顶/底 · 信息推送（用户新增要求）

> 「大的结构性双顶、双底要做信息推送，重要程度类似于现在的顶和底。小的顶和底可不推」

**口径**（唯一真源 `mw_events.is_big()`，`daily.py` 与 `data_build.py` 共用，禁止各写阈值）：

```
两峰间隔 gap ≥ 20 根  AND  颈线回撤深度 depth ≥ 3.5 ATR  →  大结构
```

10 年 370 条 M/W 中命中 **78 条（21.1%）**、近 1 年 **6 条**，频率与顶底雷达相当，
不会变成噪音。小结构一律不推，只在页面留痕。

**通道归属**：并入既有第 **⑤** 条「独立出场雷达 / 结构信息」通道的**同一次 `post_push`**，
与顶底预警同一版式、同一优先级。**v25 定稿的 6 条通道结构不变，没有第 7 条通道，
`post_push` 调用点仍是 6 处**。

| 项 | 实现 |
|---|---|
| 判定时点 | 形态「颈线确认日」= 该品种最新一根 bar（`bars[-1]['d']`），不用自然日，避免日线源延迟漏推 |
| 去重 | `state["bigMwSeen"]` 记 `sym\|date\|dir`，15:20 推过之后 15:50 兜底班不重发 |
| 闸门 | **不过路况闸门**（与 ⑤ 一致，出场/结构信息类震荡照推）；仍受 `allow_push` 品种白名单约束 |
| 纪律 | 卡片强制 `[研究参考·非建仓指令]` + 「仅为形态信息记录，不构成任何操作指令」；运行时硬断言剔除标签后扫禁词，命中即撤下该卡片 |
| 内容 | 品种、形态、第二峰日、颈线确认日、两峰间隔、颈线深度、峰1/峰2/颈线价、ATR、门槛说明 |

`data_build.py` 给每条 `mw` 加 `big` 标注，`index.mwCfg.bigRule` 输出阈值与条数供前端；
**K 线、信号、账本、回测、盲测结论一律未改**。

## 6. 边界与遗留

1. 大结构推送只在**当日新确认**时触发；若 15:20 数据未到（日线源延迟），按最新 bar 判定，
   已有记录的不会重推。
2. 归档用「形态第二峰日」定位（与图上 ★ 对齐），推送用「颈线确认日」——归档行同时显示两个日期，
   避免日期对不上。
3. `confirm` 形态仍按 v11 规则前端不展示；本次只补 `mw` / `tf`，未触碰该项。
4. 图上 ★ 仍只画 `hiConf`；部分大结构不是高置信，图上没有三角但归档行有 —— 属预期，
   对照说明里已注明以信号栏 🏔 标记为准。
