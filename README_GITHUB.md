# 期货信号台 · GitHub 免费部署（v4 反转预测雷达版）

## 信号方法（v4 反转预测雷达，仅玻璃/豆粕/螺纹钢/甲醇/尿素）

MA34 定义大趋势段（20~50 七个周期回测，34 最优），穿越点＝反转点。
反转前 10 根内回测筛出 4 条高区分度特征：
逼到 MA34 ≤0.3ATR · 10 日累计逆行 ≥1.5ATR · MA10 斜率转向 · MACD 柱翻向。
命中条数 → 反转概率（首轮触发实测 5 日内 69.4%，36 笔，提前量中位 1 根）。
**强确认层（v5 失误专项分析）**：11 笔失误中 9 笔信号日持仓 5 日仍在增加；叠加
「持仓 5 日下降 + 自极值回撤 ≥2ATR」后 19 笔中 17 笔反转（89.5%，内 91.7%/外 85.7%）。
微信推送只推强确认档（≥70% 阈值），页面看全部。
另加 **ADX(14)≥20 趋势门槛**（胜率 33.3%→40.0%）。
命中 4 条且 ADX 达标即推送"准备反转·可建仓"；
出场＝**不设止损**，持有到收盘反向穿越 MA34（新趋势走完）才离场。
历史（10 年 5 品种线上口径）36 笔：胜率 36.1%、盈亏比 3.0、年均约 3.6 笔；
⚠ 不设止损浮亏中位 0.95ATR、最深 8.7ATR（约 8,900 元/手），务必小仓并预留浮亏空间。

## 原理
GitHub Actions（免费算力）每个交易日 15:10 自动跑一次：
抓行情 → 算信号（daily.py）→ 构建分品种数据包（data_build.py）→ 生成静态页（render.py）
→ 有新信号推微信。页面托管在 GitHub Pages，手机直接访问。全程零服务器、零费用。

注意：**model_v4.json（概率标定模型）必须一并提交到仓库根目录**，engine.py 启动时会读取它。

## 三步上线（约 10 分钟）

### 1. 建仓库并上传
- GitHub 新建一个 **公开** 仓库（Pages 免费版要求公开）
- 把解压出的所有文件（保留 .github 文件夹）传上去

### 2. 开 Pages
仓库 Settings → Pages → Source 选 `main` 分支 `/ (root)` → Save
几分钟后得到 `https://<你的用户名>.github.io/<仓库名>/`，这就是手机页面。

### 3. 配微信推送（可选，2 分钟）
- 微信扫码登录 pushplus.plus → 复制 token
- 仓库 Settings → Secrets and variables → Actions → New repository secret
  Name 填 `PUSHPLUS_TOKEN`，值填 token

## 验证
仓库 Actions 页 → daily-scan → Run workflow 手动跑一次：
- 绿勾：全部正常，微信会收到历史信号初始化的说明（首次只入库不推送）
- 红叉：点开日志看是哪一步。最常见是新浪接口在海外 IP 下超时，
  若连续失败就换腾讯云方案（国内 IP，更稳）

## 已知限制（诚实版）
1. **GitHub Pages 国内访问不稳定**（github.io 时通时不通）。
   微信推送不受影响——推送里已含品种/方向/入场/离场线/手数，够用。
2. **Actions 服务器在美国**，抓新浪接口有失败可能，workflow 已配 15:40 兜底重试。
3. Actions 定时有 5~30 分钟随机延迟，属正常。
4. data/ 目录会随每日构建更新（约 5MB），属正常提交量。


## v8 趋势跟踪模块（2026-11-04 新增）

**动机**：玻璃 2026-03→10 的 7 个月空头（−400 点），反转雷达零信号——该顶部无任何
"过热/放量"特征（全程 ADX 7~20、偏离 MA34 最大 2.6ATR），反转指纹结构上抓不到。
趋势跟踪是唯一能吃到这类行情的路径。

**参数寻优**（ZigZag 确认反手，5 品种 / 10 年，训练 2016-2023 / 盲测 2024-2026）：
- 30 组参数里只有「自极值回撤 3.5×ATR 确认 + 最多持 40 根」训练盲测双正
- 成绩：254 笔、胜率 48.8%、累计 +136R、最大回撤 −27.3R、年均约 25 笔
- 多空对称（多 +72R / 空 +62R）、五品种全正（FG +42.5 / M +34.6 / RB +22.5 / MA +29.0 / UR +7.4）
- 去掉最大 5 笔仍 +73.5R；年度 8/11 年为正
- 代价：中位单笔 −0.25R（靠盈亏比赚钱）；反抽洗盘会被洗出去（玻璃 2026 全年仅 −1.3R）

**段定义检验**（用户假设"大周期定义过严"）：
- "持续≥20根 或 幅度≥200点" 与现行"≥15根且≥3ATR"几乎等价（37 vs 36 笔、+19.5R vs +20.2R）
- 彻底去掉大周期段过滤：60 笔 +32.5R，胜率/单笔不变——但有强确认层时结果完全一样，
  说明瓶颈不在段定义，在信号本身
- 价格结构（ZigZag）定义下旧 4 条特征 lift 全部 <1（原来的"贴近MA34/回撤2ATR"
  是对 MA34 交叉标签的循环论证成分），真有区分度的是"过度延伸+单日振幅+ATR放大"
  组合（5 日 +0.58ATR、胜率 67%，但 10 年仅 27 笔）

**两模块关系**：反转雷达＝趋势末端探测器（入场早、信号少、靠强确认保证质量）；
趋势跟踪＝趋势确认层（入场晚、信号多、靠盈亏比赚钱）。两者独立仓位、独立预期。
