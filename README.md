# 期货信号台 · 部署说明（当前线上 v15）

> 以下「这是什么 / 口径」章节保留 v4 时期的历史设计说明；**当前线上口径以本节为准**。

## 当前版本 v15（2026-11-08 拍板）

- **进场 / 出场底层机制不变**：MA34 定义趋势段 + 4 条特征 + ADX≥20 进场；
  MA26 反向穿越 + 吊灯 3ATR 止损离场（慢进快出，接受卖飞，不再改出场）。
- **失效打叉全量覆盖**：4/4 建仓、3/4 预警、顶底雷达，只要后续被走势证伪全部打红叉，
  信号栏单独成行、微信独立防守提示。四条标准满足其一即算失效：
  ① 收盘逆行 >1.5 ATR；② 收盘跌破/涨破 MA26 或 MA34；
  ③ 5 根内未创新高/低并收破信号日极值；④ 触发 MA26 或吊灯 3ATR 原版止损。
  规则集中在 `defend_rules.py`，`data_build.py` 与 `daily.py` 共用同一套口径。
- **A' 利润保护**：持仓浮盈峰值达 1.5 ATR 时，持仓卡显示黄字
  「💡 利润已达 1.5 ATR，可手动将止损上移至开仓价保本」；纯视觉提示，不干预后台离场线。
- 页面深链接：`?sym=XX` 选品种、`?zoom=all` 铺满 10 年看全量红叉、`?def=1` 定位最近失效、
  `?f=def` 只看失效清单、`?sig=pred|YYYY-MM-DD` 打开信号详情。

## 这是什么
一个**反转预测系统**，只针对玻璃 / 豆粕 / 螺纹钢 / 甲醇 / 尿素五个品种回测与运行。
以 MA34 定义大趋势（收盘价上/下方＝一段趋势，穿越点＝反转点；20/25/30/34/40/45/50
七个周期逐一回测，**34 的收益与回撤同时最优**）。对历史上每个反转点做事件研究：
反转前 10 根内的共性变化，经 20 条候选特征筛选，保留区分度最高的 **4 条**
（逼到 MA34 ≤0.3ATR · 10 日累计逆行 ≥1.5ATR · MA10 斜率转向 · MACD 柱翻向），
命中条数直接标定反转概率（首轮触发实测：5 日内 69.4%，36 笔）。
另加 **ADX(14)≥20 趋势门槛**：剔除"趋势还没起来"的震荡信号，胜率由 33.3% 提到 40.0%。
**强确认层（v5 失误专项分析）**：36 笔首轮触发中 11 笔失误，其中 9 笔在信号日
持仓量 5 日仍在增加（趋势资金未撤离）。叠加「持仓 5 日下降 + 自极值回撤 ≥2ATR」后
19 笔中 17 笔 5 日内反转（**89.5%**，内 91.7%/外 85.7%），不设止损收益 +18.7R→+26.5R、回撤减半。
命中 4 条且 ADX 达标 → **准备反转·可建仓**（首轮触发实测 5 日内 69.4%）；
再满足强确认两条 → 概率升至 89.5%（微信推送只推强确认档，≥70% 阈值）；
放量类与持仓减仓类指标经检验无区分度（lift<1），已淘汰。

## 口径（与回测完全一致，无前视）
- 触发：段内 4 条特征全部命中且 ADX≥20（每段趋势最多一次，方向唯一；新段至少站稳 2 根）
- 入场：命中次日开盘，按预测方向（顶→空 / 底→多）
- 出场：**不设止损**——一直持有，直到收盘反向穿越 MA34（新趋势走完）才离场；250 根安全上限仅防数据异常
- 成绩（10 年 5 品种，线上引擎口径）：36 笔，胜率 36.1%，盈亏比 3.0，年均约 3.6 笔，累计约 16,000 元/手
- 强确认层：19 笔，5 日内反转 89.5%，交易收益 +26.5R（占全部收益的大部分）
- ⚠ 不设止损的代价：持仓期浮亏中位 0.95 ATR、最深 8.7 ATR（约 8,900 元/手），务必小仓并预留浮亏空间
- ⚠ 收益集中于少数大行情，存在连续小亏期；本系统定位是"高可靠预警层 + 小仓试单"

## 文件
- engine.py     信号引擎（MA34 趋势段 + 4 特征雷达 + ADX 门槛 + 概率标定）
- model_v4.json 概率标定模型（引擎启动时读取，必须随包上传）
- daily.py      每日任务：扫描 → 推进持仓（无止损，反向穿越离场）→ 按概率阈值推送 → 写 state.json
- data_build.py 构建分品种数据包（dist/data/*.json，含实时雷达状态）
- render.py     生成静态页 dist/index.html
- serve.py      零依赖手机页服务（http.server + Basic Auth + gzip）
- notify.py     微信推送（pushplus，仅推概率 ≥70% 的建仓信号）
- build.py      新浪行情抓取与缓存
- config.json   品种池 / 本金 / 浮亏预算比例 / 推送 token / 网页账号密码
- install.sh    一键部署

## v8 趋势跟踪模块（2026-11-04 新增）

**动机**：玻璃 2026-03→10 的 7 个月空头（−400 点），反转雷达零信号——该顶部无任何
"过热/放量"特征（全程 ADX 7~20、偏离 MA34 最大 2.6ATR），反转指纹结构上抓不到。
趋势跟踪是唯一能吃到这类行情的路径。

**参数寻优**（ZigZag 确认反手，5 品种 / 10 年，训练 2016-2023 / 盲测 2024-2026）：
- 30 组参数里只有「自极值回撤 3.5×ATR 确认 + 最多持 40 根」训练盲测双正
- 成绩：254 笔、胜率 48.8%、累计 +136R、最大回撤 −27.3R、年均约 25 笔
- 多空对称（多 +72R / 空 +62R）、五品种全正（FG +42.5 / M +34.6 / RB +22.5 / MA +29.0 / UR +7.4）
- 去掉最大 5 笔仍 +73.5R；年度 8/11 年为正
- 代价：中位单笔 −0.25R（靠盈亏比赚钱）；反抽洗盘会被洗出去（玻璃 2026 全年仅 −1.3R）

**段定义检验**（用户假设"大周期定义过严"）：
- "持续≥20根 或 幅度≥200点" 与现行"≥15根且≥3ATR"几乎等价（37 vs 36 笔、+19.5R vs +20.2R）
- 彻底去掉大周期段过滤：60 笔 +32.5R，胜率/单笔不变——但有强确认层时结果完全一样，
  说明瓶颈不在段定义，在信号本身
- 价格结构（ZigZag）定义下旧 4 条特征 lift 全部 <1（原来的"贴近MA34/回撤2ATR"
  是对 MA34 交叉标签的循环论证成分），真有区分度的是"过度延伸+单日振幅+ATR放大"
  组合（5 日 +0.58ATR、胜率 67%，但 10 年仅 27 笔）

**两模块关系**：反转雷达＝趋势末端探测器（入场早、信号少、靠强确认保证质量）；
趋势跟踪＝趋势确认层（入场晚、信号多、靠盈亏比赚钱）。两者独立仓位、独立预期。

## v10.3 逐品种配置 vs 通用配置 · 测算结论（2026-11-06）

**结论：8 个品种全部使用通用配置，不按品种单独配置。**

### 判定规则（先定规则再看结果）
逐品种配置需**同时**满足三条才启用：① 样本外准确率提升 ≥ +3.0 个百分点；
② 样本外盈利率（单笔平均收益）提升 > 0；③ 两者 bootstrap 95% 置信区间下界 > 0。
否则按用户口径「没有差异或差异率极小，全部使用通用配置」。

### 品种清单
总清单 = 玻璃 FG / 纯碱 SA / 豆粕 M / 纸浆 SP / 锰硅 SM / 甲醇 MA / 白糖 SR / 玉米 C。
相对原始五品种（FG/M/RB/MA/UR）：**移除螺纹钢 RB、尿素 UR**；
**新增纯碱 SA、纸浆 SP、锰硅 SM、白糖 SR、玉米 C**。
样本：纯碱 6.9 年（1675 根）、纸浆 7.9 年（1924 根），其余 10 年（2440 根），复权与线上同源。

### 网格与方法
- 可调维度（只覆盖此前已寻优过的参数，结构性条件不动）：
  进场趋势 MA 7 档 × 持仓离场短均线 7 档 × 吊灯 5 档 = **245 组**；
  独立雷达 EXT 2.0~3.0 × PULL 0.8~1.5 = **88 组**。
- 指标：进场 = 胜率 + 净 R / 单笔 R；雷达 = 20 根方向正确率 + 单笔反向收益（ATR 倍数）。
- 选参目标：准确率与盈利率各占一半的综合分，另测「只看准确率」「只看盈利率」；
  搜索空间另测「邻近网格」（低自由度版本，减少过拟合机会）。
- 检验三层：L1 样本内 / L2 训练段(<2024)选参→盲测段(≥2024) / L3 逐年滚动 walk-forward
  （2019~2026，每年只用此前数据选参、在当年评估，**主判定依据**）；
  另补 L4（训练样本不足则回退通用）、L5（逐年前瞻判定该品种是否值得单独配的混合方案）。
  共 **10 组方案**，全部用 bootstrap 2000 次估计差异置信区间。
- 脚本：`tune_grid.py`（预计算，缓存 cache/per_grid.json）→ `tune_eval.py` → `tune_eval2.py`；
  原始输出见 `reports/`，机读结论见 `cache/tune_verdict.json`。

雷达这层数字看似占优，但两个置信区间都跨 0（样本仅 41 次），且**信号数从 65 降到 41（-37%）**，
会破坏「每品种每年 ≥3 次提示」的既有约束；进场层则直接由盈转亏。

### L3 逐年滚动样本外（主判定）
| 方案 | 进场 Δ准确率 | Δ单笔R | 雷达 Δ准确率 | Δ单笔ATR | 判定 |
|---|---|---|---|---|---|
| 全网格·综合 | **-6.5pp** | -0.65 | -2.9pp | -0.03 | 通用 |
| 邻近网格·综合 | -4.0pp | -0.16 | -1.2pp | +0.11 | 通用 |
| 全网格·准确率优先 | -2.9pp | -0.14 | **-0.6pp** | +0.21 | 通用 |
| 全网格·收益优先 | -4.5pp | -0.53 | -5.0pp | -0.11 | 通用 |

全部方案的置信区间均跨 0；进场层准确率清一色下降。
L4/L5 六组补充里最好的一组（自适应混合·准确率优先）进场 +4.5pp / +0.36R，
但 CI 为 -14.7~22.2pp 与 -0.75~+1.47R，且只触发 8 个「品种年」，**不显著**；
雷达各组差异在 **-2.0 ~ +0.5pp**、收益 **+0.01 ~ +0.13 ATR**，属于典型「差异极小」。

### 为什么逐品种不可用的三个硬证据
1. **样本外反向**：样本内平均提升十余个百分点，样本外准确率 -6.5 ~ +0.5pp，收益多为负。
2. **参数不稳定**：同一品种在 8 年滚动里被选出 1~6 套不同参数（中位数 3~4 套），
   等于实盘每 1~2 年就要换一次规则，没有可执行的稳定性。
3. **覆盖率下降**：逐品种门槛普遍更严，雷达样本外信号 193 → 160~190 次，
   盲测段 65 → 41 次，与「放宽门槛、多给提示」的既定目标冲突。

### 最终采用的最优方案（线上保持不变）
| 项 | 参数 |
|---|---|
| 配置模式 | `uniform`（8 品种共用，`engine.CONFIG_MODE`，写入 data/index.json） |
| 进场 | MA34 趋势段 + 4 条特征 + ADX(14)≥20 + 段幅≥3ATR + 强确认 |
| 持仓离场 | MA26 反向穿越 + 吊灯 3.0ATR；盘整预警 1.2ATR（只提示） |
| 独立出场雷达 | EXT 2.6ATR / PULL 1.1ATR + 6 条辅助；≥1 条建议、≥2 条强烈 |
| 关注池 | FG / SA / M / SP / SM / MA / SR / C（已移除 RB、UR 的线上数据文件） |

复核结果已写入页面「方法说明」末尾；`data/index.json` 新增 `configMode` / `uniformCfg` 便于线上核查。
